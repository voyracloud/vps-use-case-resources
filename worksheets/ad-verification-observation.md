# Regional ad and landing-page observation

Use this for an authorized review of regional presentation and landing-page consistency. It is a narrow observation record, not a fraud detector, viewability measurement system, brand-safety certification, or substitute for a professional verification provider.

## Define the authorized check

| Field | Your record |
|---|---|
| Campaign/creative alias and permission owner | |
| Expected region, language, audience and consent context | |
| Approved preview/test route and observation time | |
| Client, viewport, account/cookie state, exit evidence | |
| Creative actually visible and evidence reference | |
| Landing URL, offer, currency and disclosure consistency | |
| Unexpected behavior and competing explanations | |
| Reviewer, escalation and next check | |

Use approved preview or testing mechanisms. Do not generate artificial ad clicks, impressions, conversions, or repeated billable traffic. If a safe preview cannot reproduce the delivery context, record that limitation instead of attempting to manufacture evidence.

## Fictional example — not a product test

An advertiser's approved preview shows an English creative leading to a French-language offer page. The reviewer records the preview configuration and asks the campaign owner to verify targeting and destination rules. This hypothetical mismatch does not establish ad fraud, actual regional delivery, or a population-level campaign error.
